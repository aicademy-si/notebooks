# AiCademy notebooks

The notebooks of the AiCademy preparation for the AI Olympiads, to open in Google Colab.
Each topic has a folder: its first step (`hook`), the notebook before its session (`before`),
its `problems`, and its narrower topics in `submodules`. A name ending in `-sl` is in Slovenian.

This branch, `dev`, is copied automatically from the materials, which are written in a
private repository: do not change anything here, it is replaced at the next copy.

- **02 Core machine learning**: [hook](https://colab.research.google.com/github/aicademy-si/notebooks/blob/dev/02-core-ml/hook.ipynb)
- **03 Computer vision**: [hook](https://colab.research.google.com/github/aicademy-si/notebooks/blob/dev/03-computer-vision/hook.ipynb)
- **05 Reinforcement learning**
  - **05·03 Q-learning**: [hook](https://colab.research.google.com/github/aicademy-si/notebooks/blob/dev/05-reinforcement-learning/submodules/03-q-learning/hook.ipynb)
