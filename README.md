# AiCademy notebooks

The notebooks of the AiCademy preparation for the AI Olympiads, to open in Google Colab.
Each topic has a folder: its first step (`hook`), the notebook before its session (`before`),
its `problems`, and its narrower topics in `submodules`. A name ending in `-sl` is in Slovenian.

This branch, `main`, is copied automatically from the materials, which are written in a
private repository: do not change anything here, it is replaced at the next copy.

- **02 Core machine learning**: [hook-en](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/02-core-ml/hook-en.ipynb) · [hook-sl](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/02-core-ml/hook-sl.ipynb)
- **03 Computer vision**: [hook](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/03-computer-vision/hook.ipynb)
- **05 Reinforcement learning**: [hook-sl](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/05-reinforcement-learning/hook-sl.ipynb) · [01-robot-in-a-maze-sl](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/05-reinforcement-learning/problems/01-robot-in-a-maze-sl.ipynb)
  - **05·03 Planning and model-based methods**: [hook](https://colab.research.google.com/github/aicademy-si/notebooks/blob/main/05-reinforcement-learning/submodules/03-model-based-methods/hook.ipynb)
